# Roguemote

A 2D roguelike memory card game developed in Unity, using emoji-based visual mechanics and procedural card deck generation.

<img width="320" height="64" alt="roguemotelogo" src="https://github.com/user-attachments/assets/bbafaef9-5e97-47de-a227-c54f681ce33e" />

## 🎮 Overview

**Roguemote** combines traditional memory card matching with light roguelike elements. Cards are represented via emoji icons, requiring pattern recognition, turn tracking, and strategic decision-making within continuous game runs.

## 🛠️ Technical & Architecture Highlights

- **Procedural Deck Generation:** Dynamic card pooling and layout arrangement initialized at runtime.
- **Event-Driven Game Loop:** Decoupled turn validation, state checking, and UI updates using Unity C# events.
- **Component-Based UI Architecture:** Modular card rendering and state management ensuring scalable UI/UX flow.
- **State Management:** Finite state handling for flipping, matching, mistake tracking, and round progression.
